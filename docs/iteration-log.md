# 迭代记录

## v0.1 出游邀请页

最初版本用于收集时间、地点和餐饮选择。它能够生成一份出游结果，但没有历史数据，也无法回答“为什么推荐”。这一阶段验证了用户愿意通过轻量网页共同制定计划。

## v0.2 出游记录与偏好标签

加入出游记录、评分、备注和是否愿意再次体验。系统开始从自然语言中提取偏好与避雷标签，并使用 LocalStorage 保存数据。产品从一次性邀请页转向可持续使用的偏好工具。

## v0.3 个性化推荐

建立候选方案池和透明的排序公式，加入偏好匹配、新鲜度与近期重复惩罚。结果拆分为稳妥推荐、相似探索和惊喜选项，同时补充推荐原因。

## v0.4 地点与标签探索

加入杭州路线数据、地点预设、地图选点尝试，以及小红书、大众点评和高德地图的外部搜索入口。由于纯前端第三方接口存在密钥与域名限制，产品增加了无接口时的降级方案。

## v0.5 每日状态

加入六种当天状态，并把状态映射为不同标签权重。状态按日期存储，第二天自动失效。该变化让推荐能表达临时需求，而不必永久改变长期画像。

## v1.0 公开作品集版

移除真实姓名、私人照片、真实足迹和硬编码地图 Key；品牌统一为 MoodTrip；增加公开安全配置、项目文档、评测用例、隐私说明和 GitHub Pages 结构。界面从私人纪念页调整为可公开讲述的 AI 产品原型，同时明确当前能力属于规则基线，不夸大为模型智能。
